# 指導員 勤務予定（今日の予定ビューア）

毎月の勤務予定表PDF（`2026-12.pdf` のような名前）を置いておくと、
**開いた日の全職員の予定を自動で表示**するページです。スマホでもPCでも同じURLで開けます。

- 開くと自動で「今日」の予定を表示（出勤者・休みの人を分けて表示）
- 開きっぱなしでも日付が変わると自動で翌日に切り替え、1時間ごとにPDFを読み直し
- ◀ ▶ で前後の日も確認可能
- 「勤務表PDFで確認する」で、PDFの今日の列に色を付けて表示（読み取り結果の確認用）
- PCは毎朝7:00に自動でブラウザが開くように設定可能
- PDFをフォルダに置いておけば、毎朝6:30に自動でGitHubへ送信（Commit・Push不要）
- 16日を過ぎても次月のPDFが無ければ、メール通知＋画面にお知らせ

## フォルダ構成

```
勤務表/                       ← C:\Users\akira\OneDrive\ドキュメント\Claud作業フォルダ\勤務表
├─ 2026-11.pdf                ← 毎月ここにPDFを追加（ファイル名は 年-月.pdf）
├─ 2026-12.pdf
├─ index.html                 ← 今日の予定ページ
├─ config.js                  ← 記号（早・遅・休など）の意味や色の設定
├─ windows/
│   ├─ 毎朝の自動化_登録.bat   ← 自動送信と自動表示をまとめて設定
│   ├─ 毎朝の自動化_解除.bat
│   ├─ 今すぐ送信.bat          ← 待たずにすぐ送りたいとき
│   └─ auto-push.ps1           ← 自動送信の本体（auto-push.log に記録）
├─ js/ css/ lib/              ← プログラム本体（触らなくてOK）
└─ tests/                     ← 動作確認用（サンプルPDFは架空の名前）
```

## はじめの設定（1回だけ）

### 1. このリポジトリを「勤務表」フォルダにする
1. [GitHub Desktop](https://desktop.github.com/) をインストールして GitHub にログイン
2. 「File → Clone repository」で `akira-1229/Staff-Schedule` を選び、
   保存先（Local path）を `C:\Users\akira\OneDrive\ドキュメント\Claud作業フォルダ\勤務表` にする

### 2. GitHub Pages を有効にする（スマホから開けるようにする）
1. GitHub のリポジトリ画面 → **Settings → Pages**
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後に `https://akira-1229.github.io/Staff-Schedule/` で開けるようになります

> ⚠️ 無料プランでは、GitHub Pages は**公開（Public）リポジトリ**でしか使えません。
> 公開にすると、URLを知っている人は勤務表（職員の名前）を見られます。
> 非公開のまま使う場合は GitHub Pro などの有料プランが必要です。

### 3. スマホのホーム画面に追加
- iPhone（Safari）：URLを開く → 共有ボタン → 「ホーム画面に追加」
- Android（Chrome）：URLを開く → メニュー → 「ホーム画面に追加」

以後はアイコンをタップするだけで、その日の予定が表示されます。

### 4. 毎朝の自動化を設定
1. [Git for Windows](https://git-scm.com/download/win) をインストール（初期設定のままでOK）
2. `windows\毎朝の自動化_登録.bat` をダブルクリック。次の2つが設定されます
   - **毎日 6:30**：新しいPDF・差し替えたPDFがあれば自動でGitHubへ送信（無ければ何もしない）
   - **毎日 7:00** と **Windowsにサインインしたとき**：ブラウザで今日の予定を開く
   - 6:30にPCの電源が切れていた場合は、PCを起動したあとに送信します
3. 最初の1回だけ `windows\今すぐ送信.bat` をダブルクリック。
   GitHubのログイン画面が出たらログインしてください（以後は不要）

時刻は bat の `PUSH_TIME=06:30` / `OPEN_TIME=07:00` を書き換えて、もう一度 bat を実行すると変わります。
やめるときは `毎朝の自動化_解除.bat` をダブルクリック。

送信の結果は `windows\auto-push.log` に記録されます。予定が更新されないときはここを見てください。

## 毎月やること

**来月の勤務表を `2026-12.pdf` のような名前で「勤務表」フォルダに保存するだけ**です。

翌朝6:30に自動でGitHubへ送られ、その月になると新しいPDFから予定が表示されます。
すぐに反映したいときは `windows\今すぐ送信.bat` をダブルクリックしてください（反映まで1〜2分かかります）。

- 送信されるのは `年-月.pdf`（例：`2026-12.pdf`）の名前のファイルだけです。
  `下書き.pdf` などほかのファイルは送られません
- 同じ名前で上書き保存すれば、差し替えも自動で送られます

## 次月の勤務表が未アップロードのときの通知

毎月16日以降、次月のPDF（例：11月なら `2026-12.pdf`）がまだ無いと：

- **メール・GitHubアプリに通知**：毎朝9:10ごろ GitHub が確認し、「【勤務表】2026-12 の予定表がまだアップされていません」
  というお知らせ（Issue）を作ります。その後も3日おきに再通知します。PDFが届くと自動で閉じます
- **画面にお知らせ**：今日の予定ページの上に黄色い帯で表示します

通知を始める日は `.github/workflows/next-month-reminder.yml` の `REMIND_AFTER_DAY`（メール）と
`config.js` の `remindAfterDay`（画面）で変えられます。
メールが届かないときは GitHub の Settings → Notifications で「Email」が有効か確認してください。

## PDFの形について

次のような表を読み取ります（Excel等から「PDFとして保存」したもの）。

| 氏名 | 1 | 2 | 3 | … | 31 |
|------|---|---|---|---|----|
| 山田 太郎 | 早 | 休 | 遅 | … | 日 |

- 見出しの日付は `1` `1日` `1(月)` のどれでもOK。曜日の行があってもOK
- 空欄のセルは「予定なし」として休みの欄に表示
- **スキャンした画像のPDF**は文字が読めないため、一覧は出ず、PDFの表示のみになります
- 記号の意味（早番・遅番など）や勤務時間、色は `config.js` で変更できます

## 動作確認（開発者向け）

```
node tests/pdf-schedule.test.js
```

ローカルで表示を確認するときは、フォルダで `python -m http.server` を実行し
`http://localhost:8000/?date=2026-11-06` を開きます（`?date=` で日付を指定可能）。
※ index.html をダブルクリックで直接開くと、ブラウザの制限でPDFを読み込めません。
