# 指導員 勤務予定（今日の予定アプリ）

**URL：https://akira-1229.github.io/Staff-Schedule/**

<img src="qr.png" alt="今日の勤務予定ページのQRコード" width="200">

（スマホのカメラで読み取ると開きます。GitHub Pages を有効にした後から使えます）

👉 **最初の設定手順は [はじめに_やること.md](はじめに_やること.md) にまとめています**

アプリ（ページ）を開くと、**その日の全職員の勤務予定を自動で表示**します。
予定表と班編成表は、アプリの **⚙（設定）からアップロード**するだけです。スマホでもPCでも同じように使えます。

## できること

- 開くと「今日」の予定を、出勤・休みに分けて表示（◀ ▶ で前後の日も確認）
- 班編成表をアップロードしておくと、各職員の班と、班ごとの出勤人数も表示
- 開きっぱなしでも日付が変わると自動で切り替え、1時間ごとに最新の予定表を読み直し
- 「予定表PDFで確認する」で、PDFの今日の列に色を付けて表示（読み取り結果の確認用）
- 毎朝6:40ごろ、その日の全職員の予定を GitHub アプリにプッシュ通知（アプリを閉じていても届く）
- アップロード忘れのお知らせ（メール・GitHub アプリ・画面）
  - **予定表**：16日を過ぎても次月の予定表が無いとき
  - **班編成表**：4月になってもその年度の班編成表が無いとき（4月中にアップロードする決まり）

## アップロードするもの

| ファイル | いつ | 設定画面での選び方 |
|---|---|---|
| **予定表**（PDF） | 1か月または2か月に一度（次月分を前月中に） | 「何月から」と「1か月分／2か月分」を選んで、PDFを選ぶ |
| **班編成表**（PDF） | 1年に一度、**毎年4月中** | 「年度」を選んで、PDFを選ぶ |

- PDFを選ぶと、その場で読み取りを確認します（「✓ 12月：5人の予定を読み取れました」など）
- アップロードした端末にはすぐ反映され、ほかの端末・スマホには1〜2分で反映されます
- 同じ月をもう一度アップロードすると、新しい方に差し替わります
- **アップロードするには「GitHubの鍵」が必要**です（アップロードする人の端末だけ。見るだけの人は不要）

## PDFの形について

**予定表**：Excel などから「PDFとして保存」した、次のような表

| 氏名 | 1 | 2 | 3 | … | 31 |
|------|---|---|---|---|----|
| 山田 太郎 | 早 | 休 | 遅 | … | 日 |

- 見出しの日付は `1` `1日` `1(月)` のどれでもOK。曜日の行があってもOK。空欄は「予定なし」
- 2か月分のPDFは、ページごと・1ページに上下2つ、どちらでもOK
  （表の上の「2026年12月」などで月を見分けます。無ければ並び順で判断）
- 記号の意味（早番・遅番など）・時刻・色は `config.js` で変更できます

**班編成表**：次のどれかの形

- 見出し行に「1班 2班 3班」、その下に各班の氏名が縦に並ぶ
- 「A班　山田 太郎　高橋 美咲」のように、班名の行に氏名が横に並ぶ
- 「ひまわり班」の行のあと、次の班名までの行に氏名が並ぶ

氏名は予定表と同じ書き方にしてください（空白の有無は問いません）。

**スキャンした画像のPDF**は文字が読めないため、一覧は出ず、PDFの表示のみになります。

## 毎朝の通知（GitHubアプリ）

毎朝6:40ごろ、GitHub がその日の予定を読み取り、「【毎朝のお知らせ】2026年11月の勤務予定」という Issue にコメントします。
`notify-users.txt` に書いた人を @メンションするので、GitHub アプリにプッシュ通知が届きます。

```
@akira-1229 11/6（金） 出勤3人：佐藤花子（日） 鈴木一郎（遅） 高橋美咲（日）
```

- 受け取る人：GitHub アカウントを作り、スマホに GitHub アプリを入れてプッシュ通知と「Direct mentions」をオン
- 通知先の追加：`notify-users.txt` に GitHub ユーザー名を1行ずつ書く
- 出勤者0人の日（休業日）は通知しません（`.github/workflows/daily-notify.yml` の `NOTIFY_ON_CLOSED_DAYS`）
- GitHub の混雑で、数分〜数十分遅れて届くことがあります

## アップロード忘れのお知らせ

毎朝9:10ごろ GitHub が確認し、必要なら「【予定表】2026-12 の予定表がまだアップロードされていません」
「【班編成表】2027年度の班編成表がまだアップロードされていません」というお知らせ（Issue）を作ります。
3日おきに再通知し、アップロードされると自動で閉じます。アプリの画面上部にも黄色い帯で表示されます。

予定表のお知らせを始める日は `scripts/reminders.js` の `REMIND_AFTER_DAY`（メール・アプリ）と
`config.js` の `remindAfterDay`（画面）で変えられます（どちらも今は15＝16日から）。

## PCで毎朝自動で開く（任意）

`windows\毎朝自動で開く_登録.bat` を PC に保存してダブルクリックすると、毎日7:00と Windows にサインインしたときに、
ブラウザでこのページが開きます。やめるときは `毎朝自動で開く_解除.bat`。

## ファイル構成（開発者向け）

```
index.html, css/, js/app.js   アプリ本体
js/pdf-schedule.js            PDFの読み取り（予定表・班編成表）
js/store.js                   アップロードと登録情報（data/manifest.json）
schedules/  teams/            アップロードされたPDF
data/manifest.json            どのPDFが何月・何年度のものか
config.js                     表示名・記号・アップロード先
scripts/                      毎朝の通知・お知らせ用（GitHub Actions から実行）
lib/pdfjs/                    PDF読み取りライブラリ（pdf.js）
tests/                        テスト（サンプルPDFは架空の名前）
```

```
node tests/pdf-schedule.test.js      # 読み取りのテスト
node tests/make-fixtures.js          # サンプルPDFを作り直す（Playwright が必要）
```

ローカルで確認するときは `python -m http.server` を実行し、`http://localhost:8000/?date=2026-11-06` を開きます。
